Instalação e uso no Windows

Usa Linux ou Mac? Veja a instalação no Linux e no Mac.

Os jogadores não instalam nada: abrem o link no navegador (Chrome, Edge, Firefox ou celular). Este guia é para quem hospeda a mesa, ou seja, o mestre.

Capítulo I1. Instalar (uma vez só)

  1. Instale o Node.js, versão LTS, em https://nodejs.org, com as opções padrão.
  2. Organize as pastas assim (o nome da pasta de fora pode ser qualquer um):

tabula\ ├── campanha\ ← criada sozinha na primeira vez; é onde a campanha mora ├── Tabula_v2\ ← a versão que você usa └── Tabula_v1\ ← versões antigas, se quiser guardar

  1. Dentro da pasta da versão, dê dois cliques em instalar.bat e espere aparecer "Pronto!".

Se o Windows mostrar "O Windows protegeu o computador", clique em Mais informações → Executar assim mesmo.

Capítulo II2. Abrir a mesa

Atalho Quando usar
iniciar.bat Todos na mesma casa / mesmo Wi-Fi, ou só você testando
online.bat Amigos jogando de outras casas

A janela preta precisa ficar aberta durante o jogo. Minimizar pode; fechar encerra a mesa.

Na primeira vez, a mesa pede para você criar a conta do mestre (nome e senha). Anote a senha.

Capítulo III3. Jogar online

  1. Abra o online.bat. Na primeira vez, ele tenta instalar o cloudflared sozinho; se conseguir, feche a janela e abra de novo.
  2. Ele abre duas janelas: a da mesa e a do túnel.
  3. Na janela do túnel, procure uma caixinha assim:

| Your quick Tunnel has been created! Visit it at ... | | https://palavras-aleatorias.trycloudflare.com |

  1. Mande esse link para os jogadores (selecione com o mouse e aperte Enter para copiar).

⚠ O link muda toda vez que você abre o online.bat. Mande o novo a cada sessão.

Antes de mandar, teste o link no celular com o Wi-Fi desligado (usando os dados móveis).

Se o cloudflared não instalar sozinho, baixe cloudflared-windows-amd64.exe em https://github.com/cloudflare/cloudflared/releases/latest, renomeie para cloudflared.exe e coloque na pasta da versão.

Capítulo IV4. Jogar presencialmente

  • Abra o iniciar.bat. A janela mostra o endereço "Na mesma rede/Wi-Fi" (ex.: http://192.168.15.55:3000).
  • Todos no mesmo Wi-Fi abrem esse endereço no celular.
  • Na primeira vez, o Windows pergunta sobre o firewall: permita em redes privadas.
  • Para uma TV mostrando só o mapa: crie um usuário do tipo Telão (só assiste) e entre com ele no navegador da TV.

Capítulo V5. Fechar a mesa

Qualquer um destes salva a campanha e cria um ponto de backup:

  • No navegador: Mestre → Sessão e backups → ⏻ Salvar e encerrar a sessão (avisa os jogadores na tela deles).
  • Na janela preta: Ctrl + C, ou fechar no X.

Capítulo VIOnde fica a campanha

campanha\
├── campaign.json          ← a campanha inteira (salva a cada alteração)
├── campaign.backup.json   ← cópia de como estava quando a mesa abriu
├── backups\               ← pontos de backup datados (abertura, a cada 30 min, encerramento…)
└── uploads\               ← mapas e imagens enviadas
  • Para fazer uma cópia de segurança, copie a pasta campanha inteira (Google Drive, pendrive…).
  • Para levar para outro computador, leve a pasta campanha junto e coloque ao lado da pasta da versão.

Capítulo VIIAtualizar para uma versão nova

A partir da v5, é um clique:

  1. Feche a mesa.
  2. Dê dois cliques em atualizar.bat, dentro da pasta da Tábula.

Ele baixa a versão mais nova do GitHub, guarda uma cópia da versão atual em Tabula_anterior (ao lado), copia os arquivos novos por cima e roda o npm install. A campanha não é tocada, porque fica na pasta campanha. Quando sai uma versão nova, o mestre vê um aviso no topo da mesa.

Com isso, não precisa mais de uma pasta por versão: dá para renomear a pasta para só Tabula. Se a atualização der problema, a versão anterior está em Tabula_anterior e abre a mesma campanha.

Vindo da v4.1 ou anterior (ainda sem o atualizar.bat): extraia a v5 ao lado das outras pastas, na mesma pasta onde está a campanha, rode instalar.bat e depois iniciar.bat. Daí em diante, use o atualizar.bat.

Capítulo VIIIProblemas comuns

O que aparece O que fazer
EADDRINUSE ou "Já tem uma mesa aberta" Outra mesa está aberta. Feche a outra janela preta. Se não achar, abra o Prompt de Comando e rode taskkill /IM node.exe /F
"O Node.js não está instalado" logo depois de instalar Feche e abra o .bat de novo. Se continuar, reinicie o computador
Esqueci a senha do mestre Feche a mesa e dê dois cliques em redefinir-senha.bat: escolha o usuário e digite a senha nova
Esqueci a senha de um jogador Mestre → Jogadores e personagens → 🔑 ao lado do nome
Token "não aparece" ou fica minúsculo A grade não bate com o mapa. Mestre → Cena ativa (grade) → informe Quadrados na largura
Jogadores não conseguem entrar pelo link Confira se as duas janelas (mesa e túnel) estão abertas e se mandou o link desta sessão
Celulares no Wi-Fi não entram Permita o Node.js no firewall do Windows (redes privadas)
atualizar.bat diz que não conseguiu baixar Confira a internet. Dá para baixar à mão em https://github.com/LP-IQ/tabula/archive/refs/heads/main.zip e copiar por cima, menos a pasta data

Instalação e uso no Linux e no Mac

Os jogadores não instalam nada: abrem o link no navegador, em qualquer sistema. Este guia é para quem hospeda a mesa num computador com Linux ou macOS. No Windows, veja a instalação no Windows.

A mesa é a mesma do Windows; só os atalhos mudam: no lugar dos .bat há os .sh, que rodam no terminal.

Windows Linux e Mac Para quê
instalar.bat ./instalar.sh instalar (uma vez só)
iniciar.bat ./iniciar.sh abrir a mesa para jogar em casa
online.bat ./online.sh abrir a mesa e o link para jogar pela internet
atualizar.bat ./atualizar.sh baixar a versão nova do GitHub
redefinir-senha.bat ./redefinir-senha.sh trocar a senha de alguém (com a mesa fechada)

Capítulo I1. Instalar (uma vez só)

  1. Instale o Node.js 18 ou mais novo:
    • Ubuntu, Debian, Mint, Pop!_OS: o apt install nodejs costuma trazer uma versão velha. Use o instalador do site: https://nodejs.org/pt/download, opção Linux, com nvm.
    • Fedora: sudo dnf install nodejs
    • Arch, Manjaro: sudo pacman -S nodejs npm
    • Mac: o instalador do site https://nodejs.org, ou brew install node
  2. Baixe a Tábula (https://github.com/LP-IQ/tabula/archive/refs/heads/main.zip) e descompacte. Organize as pastas assim:

tabula/ ├── campanha/ ← criada sozinha na primeira vez; é onde a campanha mora └── Tabula/ ← os arquivos da Tábula

  1. Abra um terminal dentro da pasta da Tábula (no gerenciador de arquivos, botão direito → Abrir no terminal) e rode:

./instalar.sh

Se aparecer Permissão negada, rode antes chmod +x *.sh (alguns descompactadores tiram a permissão de execução). Também dá para rodar sem ela: bash instalar.sh.

Capítulo II2. Abrir a mesa

./iniciar.sh

O navegador abre sozinho em http://localhost:3000. O terminal precisa ficar aberto durante o jogo; Ctrl + C fecha a mesa e salva a campanha.

Na primeira vez, a mesa pede para você criar a conta do mestre (nome e senha). Anote a senha.

Capítulo III3. Jogar online

./online.sh

Na primeira vez, ele baixa o cloudflared (o programa que cria o link) para dentro da pasta da Tábula. Depois abre a mesa e mostra, num quadro, o endereço terminando em .trycloudflare.com: mande esse endereço para os jogadores. Você mesmo pode usar http://localhost:3000.

Tudo roda num terminal só. Ctrl + C fecha o link e a mesa, salvando a campanha. O que a mesa escreve fica no arquivo tabula.log, e o do link em tunel.log, se precisar investigar algo.

O endereço muda a cada vez que você abre o online.sh. Mande o novo antes de cada sessão.

Capítulo IV4. Jogar presencialmente

Rode ./iniciar.sh. O terminal mostra o endereço "Na mesma rede/Wi-Fi" (algo como http://192.168.0.12:3000): os celulares na mesma rede entram por ele. Se não conseguirem, o firewall pode estar bloqueando a porta 3000 (no Ubuntu: sudo ufw allow 3000/tcp).

Capítulo V5. Atualizar

Com a mesa fechada:

./atualizar.sh

Ele só atualiza se a versão do GitHub for mais nova. Antes, guarda uma cópia da versão atual em Tabula_anterior (ao lado); depois copia os arquivos novos e roda o npm install. A campanha não é tocada.

Capítulo VIProblemas comuns

O que aparece O que fazer
Permissão negada ao rodar um .sh chmod +x *.sh na pasta da Tábula, ou rode com bash nome.sh
"O Node.js deste computador é antigo" Instale o Node.js pelo site (nvm), não pelo apt
"Já existe uma mesa aberta" Feche o outro terminal da mesa. Se não achar: pkill -f "node server.js"
Esqueci a senha do mestre Feche a mesa e rode ./redefinir-senha.sh
O link do online.sh não aparece Confira a internet; o motivo fica no fim do tunel.log
O navegador não abriu sozinho Abra você mesmo http://localhost:3000
